📄 Surat Rasmi MY

Penjana surat rasmi Bahasa Melayu untuk pelajar Malaysia. Malay formal letter generator for students. Installable PWA, works offline, no data leaves your device.


Live: https://github.com/fiylim/Surat-Rasmi-MY


Templat / Templates

Cuti kelas · Cuti sakit · Lanjutan tarikh tugasan · Rayuan · Surat pengesahan pelajar


Format

Alamat pengirim → tarikh → penerima → salam → PER: → isi (perenggan bernombor) → Sekian, terima kasih. → (cogan kata) → Yang benar, → tandatangan & nama.



⚠️ Tiada satu format piawai untuk semua institusi. Semak dengan pensyarah / pejabat anda.



Sumbang / Contribute

Edit templates.js (tiada pengetahuan coding diperlukan) dan buka Pull Request. Tambah templat baru, betulkan bahasa, atau tambah format institusi anda.


Jalankan setempat

python3 -m http.server kemudian buka localhost:8000.
